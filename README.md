# Canvas-Fun

The files titled, "Different, Separate App 1 (study) - Frontend" and "Different, Separate App 1 (study) - Backend" are NOT part of the Google Apps Script App titled "Canvas Fun".  These files are SEPARATE apps that the user has included in this repository simply for the sake of reusing some of their code in the files of which the main application (Canvas Fun) is composed.

## Updates
* Robust console logging and a notification toast system have been added, similar to the functionality found in the reference code for the Study App.
